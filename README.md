# 3D

Wolfenstein 3d-like renderer. Uses webgl for rendering. Created using chatgpt (I don't know how to work with webgl, so decided to try ai to write the webgl code)

# Functionality:
- Map generator
- Video texture with playback controls
- Vertical movement, which gives the ability to see top faces of the walls

# Controls:
- Arrows up/down: forward/backward
- Arrows left/right: rotate left/right
- W/S: rotate camera up/down
- A/D: strafe left/right
- Q/E: move camera vertically
